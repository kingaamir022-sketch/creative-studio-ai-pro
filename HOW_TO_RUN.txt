CreativeStudio AI Pro v2.6.0 — Kaise chalana hai (How to run)
=============================================================

DESKTOP APP (sab se asaan — pehli dafa bhi, har dafa bhi):
1. "CreativeStudio AI Pro.exe" par double-click karein
   (ya Start Menu / Desktop shortcut se kholein).
2. App khud server start karke apni window mein khul jayegi —
   browser ya terminal ki zaroorat nahi.
3. Pehli dafa Sign up karein — pehla account OWNER banta hai.
   Band karne ke liye window band kar dein — server khud band ho jata hai.

FALLBACK (agar exe na chale):
1. Isi folder mein Start.bat par double-click karein —
   ye browser mein http://localhost:4820 khol dega.
2. Ya terminal mein: npm start, phir browser mein http://localhost:4820
   (is ke liye Node.js install hona chahiye: https://nodejs.org — LTS).

Agar "localhost refused to connect" aaye to matlab server chal nahi raha —
app band karke dobara kholein, ya Start.bat dobara chalaiye.

Aap ka data (projects, uploads, database) app folder ke andar
data/ , uploads/ aur renders/ mein rehta hai — update ya dobara
install par ye folders delete NAHI hote.

Details: docs/INSTALL.md
